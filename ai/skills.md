## Tips

### Other Names

| Name                                 | Who                                                              | How it relates                                                                                                                                     |
| ------------------------------------ | ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Agent Skills (SKILL.md)              | Anthropic, now an open format that other coding agents also read | Closest match: frontmatter with name + description, a markdown body that is loaded only when relevant. Only the short descriptions stay in context |
| Agent Operating Procedures (AOPs)    | Decagon                                                          | Procedures written in natural language that steer a support agent through a known scenario and the calls it makes                                  |
| Procedures                           | Intercom Fin                                                     | Same idea: standard procedures written for the AI agent                                                                                            |
| Topics (instructions + actions)      | Salesforce Agentforce                                            | Classifies the intent, then applies instructions and a set of actions scoped to that intent                                                        |
| Dynamic few-shot / example selectors | LangChain and similar libraries                                  | The retrieval part: pick worked examples by embedding similarity and add them to the prompt                                                        |
| Procedural memory                    | Agent-memory research and libraries                              | The theory name for “how to do X” knowledge, as opposed to facts                                                                                   |
| Recipes                              | Block’s Goose                                                    | Same word, different thing: saved workflows the user starts, not guidance the agent retrieves                                                      |
