### Installation

```sh
# Using NPM
npm install expo-cli -g # The global expo-cli package has been deprecated. To use the local CLI instead (recommended in SDK 46 and higher), run: npx expo <command>
```

### Commands

```sh
# Using NPX
npx expo -h
```

### Usage

```sh
#
npx expo login

#
npx expo whoami

#
npx expo config
```
